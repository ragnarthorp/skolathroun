# Höfundar greina og pistla 2016–2026

Gagnvirk skrá yfir 285 greinar og pistla og höfunda þeirra. Opnaðu `index.html` í vafra eða hýstu möppuna, til dæmis á GitHub Pages.

- **Greinar og pistlar:** leit í titlum og nöfnum höfunda (kommur skipta ekki máli, „olafur“ finnur „Ólafur“), síun eftir flokki og árabili, röðun eftir ári, titli eða númeri.
- **Höfundar:** yfirlit yfir hve margir höfundar eiga 1, 2, 3 … greinar (smelltu á línu til að sjá þá höfunda) og tafla raðað eftir fjölda greina, flokkuð eftir fjölda. Einnig má raða eftir færslum, pistlum eða nafni. Talningin fylgir völdum síum. Smelltu á nafn til að sjá færslur höfundarins.
- **Fjöldi eftir árum:** smelltu á súlu til að skoða eitt ár.

Gögnin eru í `gogn/hofundayfirlit.md` og eru felld inn í `index.html`. Síðan er ein HTML-skrá sem þarf ekki netþjón.
